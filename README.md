서울 지하철 승하차 데이터 파이프라인

서울시 지하철 호선별·역별 승하차 인원 데이터를 PostgreSQL에 적재하고, SQL로 분석하는 데이터 엔지니어링 토이프로젝트입니다.

데이터 출처
서울 열린데이터광장, 「서울시 지하철호선별 역별 승하차 인원 정보」 (제공: 서울특별시)
교통카드 기반 집계이며, 환승객 여부와 상관없이 집계된 수치입니다.
이용 조건은 해당 데이터셋 상세 페이지를 따릅니다.
기술 스택

Python, Pandas, PostgreSQL, Docker

구조 (예정)

raw (원본 그대로) → staging (컬럼명·타입 정리, 중복 제거) → mart (분석용 테이블)
